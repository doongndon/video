# Montage — 브라우저 영상 편집기

Premiere Pro의 작업 방식(프로젝트 패널 → 소스/프로그램 모니터 → 멀티트랙 타임라인 → 효과 컨트롤 → 내보내기)을 본뜬 **브라우저 기반 비선형 영상 편집기(NLE)**입니다. 화면은 모두 한국어이고, 설치나 서버 없이 브라우저 안에서만 동작합니다. 미디어 파일은 사용자 컴퓨터 밖으로 나가지 않습니다(자동 자막의 모델 다운로드만 예외, 아래 참고).

> Adobe와 무관한 독립 구현입니다. Adobe 코드·디자인·상표를 사용하지 않았고, 단축키와 패널 구성 같은 작업 흐름만 참고했습니다. Premiere Pro의 모든 기능을 갖춘 복제품은 아닙니다(아래 "알려진 제한" 참고).

## 실행 방법

ES 모듈을 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 정적 웹 서버로 열어야 합니다.

```bash
# 저장소 루트에서 아래 중 하나
python3 -m http.server 8000
npx serve .
```

브라우저에서 `http://localhost:8000` 을 엽니다. 빌드 단계는 없습니다. 처음 열면 샘플 프로젝트와 **시작 가이드**가 나옵니다(`?blank`를 붙이면 빈 프로젝트로 시작).

**권장 브라우저:** 최신 Chrome / Edge. WebCodecs, Canvas `filter`, WebGL/WebGL2, AudioWorklet을 사용합니다.
- MP4(H.264/AAC) 디코딩·인코딩은 브라우저 코덱 지원에 따라 달라집니다. H.264를 지원하지 않는 브라우저(예: 일부 Linux 빌드의 Chromium)에서는 WebM으로 내보내면 됩니다. 개발 환경의 Chromium에는 H.264 인코더가 없어 **MP4 내보내기 경로는 직접 시험하지 못했습니다.**
- Firefox와 Safari는 테스트하지 않았습니다.

## 보기 쉽게 쓰기
- **보기 ▸ 화면 크기**: 작게 / 보통 / 크게 / 아주 크게 (글자·버튼·타임라인 글씨가 함께 커짐)
- **창 ▸ 작업 영역**: 편집, 색상 보정, 오디오, 효과, 자막·그래픽, 멀티캠, 검토(모니터 크게) 배치
- 버튼은 아이콘 + 한국어 설명(마우스를 올리면 단축키 표시), 대화상자는 쉬운 말 위주
- **도움말 ▸ 시작 가이드**, **단축키 목록(F1)**

## 휴대폰에서 쓰기
폭이 좁은 화면(760px 이하)이나 가로로 눕힌 휴대폰에서는 **휴대폰 화면 배치**로 바뀝니다. 같은 프로젝트와 기능을 그대로 쓰고, 화면만 손가락에 맞게 바뀝니다.
- 세로: 위에 미리보기, 가운데 타임라인, 아래에 도구 막대. 가로: 왼쪽 미리보기, 오른쪽 타임라인
- **＋ 버튼**: 영상·사진·음악을 골라 재생헤드 위치에 차례로 넣기. 미디어 목록의 "넣기" 버튼도 같은 일
- **아래 도구 막대**: 미디어, 텍스트, 스티커, 애니메이션, 필터, 효과, 소리, 화면, 자동 편집, 조정, 더보기. 누르면 아래(가로일 때는 오른쪽)에서 시트가 올라오고, 손잡이를 누르면 크게/작게
- **클립 도구 막대**(클립을 고르면 나타남): 분할, 삭제(빈자리 당김), 복제, 속도, 역재생, 정지 화면, 애니메이션, 필터, 위치·크기, 소리, 세부 조정, 선택 해제
- 타임라인 손가락 조작: 끌어서 이동, 두 손가락 벌리기/오므리기로 확대/축소, 탭으로 클립 선택(빈 곳은 재생헤드 이동), 선택한 클립은 끌어서 옮기거나 양쪽 끝 손잡이로 길이 조절, 길게 누르면 클립 메뉴
- 미리보기 손가락 조작: 선택한 클립을 끌어서 옮기기, 두 손가락으로 크기(벌리기)·회전(비틀기, 90°마다 살짝 붙음)·위치 바꾸기
- 위 막대의 ☰ 버튼으로 데스크톱의 전체 메뉴를 모두 쓸 수 있음. 대화상자는 아래에서 올라오는 시트로 표시
- 세로 화면의 시트는 미리보기와 재생 버튼 바로 아래부터 열려, 시트를 연 채로 재생할 수 있음. 시트 안에서 글자를 입력하면(키보드가 올라오면) 시트가 화면 전체로 커져 입력 칸이 가려지지 않음

## 기능

### AI 편집 (Gemini, 메뉴 AI ▸ / 창 ▸ AI 편집)
본인의 **Gemini API 키**(Google AI Studio에서 발급)를 넣으면 브라우저가 Google Gemini API에 직접 연결합니다. 이 편집기에는 따로 서버가 없습니다.
- **AI로 전체 편집하기** (AI 탭 ▸ 전체 편집): 스타일(브이로그·쇼츠·정보·감성 여행·예능)과 목표 길이를 고르고 시작하면 차례로 — 화면 비율(쇼츠는 9:16로 바꾸고 화면 채우기) → 말 없는 구간 잘라내기 → 자막 만들기(없을 때) → **Gemini가 자막을 읽고** 말 실수·덜 중요한 부분 잘라 길이 맞추기, 오프닝 제목, 강조 문구·스티커, 챕터 마커, 맞춤법 → 컷 사이 전환과 처음·끝 페이드 → 색 필터 → 자막 모양 → 배경음악(말할 때 줄이기, 끝에 맞춰 자르고 페이드 아웃). 배경음악은 자르지 않고 이어서 깔림. 할 일을 하나씩 끄고 켤 수 있고, 진행 상황이 단계마다 보이며, 전체가 **실행 취소 한 번**으로 되돌아감. Gemini 키가 없으면 자막은 Whisper로 만들고 내용 편집은 건너뜀(프로젝트 이름으로 제목만)
- **AI 편집 도우미**: "앞 3초 잘라 줘", "자막 맞춤법 고쳐 줘", "30초 하이라이트 만들어 줘"처럼 말로 요청하면 Gemini가 편집 도구를 골라 실행합니다. 쓸 수 있는 도구: 구간 잘라내기(빈자리 당김), 클립 지우기, 분할, 자막·글자 고치기, 자막 트랙 추가(번역 등), 제목 넣기, 마커, 필터, 애니메이션, 볼륨, 속도, 전환, 스티커, 화면 비율, 재생헤드 이동. 요청 한 번의 편집은 **실행 취소 한 번**으로 모두 되돌아감. 자주 쓰는 요청 버튼(맞춤법, 말 실수 잘라내기, 하이라이트, 마커, 영어 자막, 제목·설명·해시태그, 강조 문구, 쇼츠로 바꾸기)
- AI는 **영상 화면과 소리를 보지 않습니다.** 매번 타임라인 정보(트랙, 클립 이름·시간, 자막·글자 내용, 마커)만 보내므로, 내용에 따른 편집은 자막이 있어야 제대로 됩니다
- **대본으로 편집**: 자막을 한 줄씩 보며 글자를 고치고, 찾아 바꾸기, 체크한 줄을 **자막만 지우기**(잘못 받아 적은 줄) 또는 **영상에서 잘라내기**(그 말을 한 구간을 모든 트랙에서 잘라 냄, 텍스트 기반 편집). 이 기능은 키 없이 씁니다
- **Gemini 자동 자막**: 자동 자막 창에서 엔진을 Gemini로 고르면 섞인 소리를 3분씩 나눠 Gemini로 보내 받아 적습니다
- 모델은 키로 쓸 수 있는 목록을 불러와 고르고, 고르지 않으면 가장 알맞은 안정판 Flash 모델을 자동으로 씁니다. 키는 기본적으로 탭을 닫으면 지워지고, "이 브라우저에 기억하기"를 켜면 이 브라우저에 저장됩니다

### 빠른 편집 (쉬운 꾸미기, 창 ▸ 빠른 편집)
- **애니메이션**: 등장 12종(페이드, 확대, 밀려 들어오기, 통통 튀기, 고무줄, 회전, 타자기 등), 퇴장 8종, 계속 움직이기 7종(켄 번즈 확대/축소, 좌우 이동, 둥실둥실, 흔들흔들, 두근두근, 떨림). 모션·불투명도 키프레임으로 들어가므로 효과 컨트롤에서 더 다듬을 수 있음
- **필터 15종**(선명하게, 화사하게, 따뜻하게, 시원하게, 영화처럼, 빈티지, 필름, 레트로, 몽환, 무드, 노을, 푸른 밤, 핑크빛, 흑백, 흑백 대비): 지금 화면으로 만든 미리보기 그림을 보고 고르고, 강도 조절. 고급 색상 보정 효과로 들어감
- **글자 스타일 10종**, **스티커**(이모지 56개, 톡 튀어나오며 등장)
- **화면**: 화면 비율 바꾸기(16:9, 9:16, 1:1, 4:5, 4:3, 21:9), 화면 속 화면(네 모서리·가운데·맞춤·꽉 채우기, 크기), **빈 곳 채우기**(흐린 배경 또는 단색), 시퀀스 배경색
- **소리**: 볼륨, 페이드 인/아웃, 소리 끄기, **목소리 효과 9종**(로봇, 전화, 라디오, 확성기, 동굴, 공연장, 메아리, 물속, 또렷하게), 보이스오버·오디오 추출·자동 더킹 바로가기
- **자동 편집**: 무음 구간 자동 삭제, 비트 마커, 사진 슬라이드쇼, 자동 자막, 장면 감지
- **무음 구간 자동 삭제(점프 컷)**: 파형에서 기준보다 조용한 구간을 찾아 잘라 내고 빈자리를 당김. 조용하다고 볼 크기·최소 길이·앞뒤 여유를 정하고, 지울 구간 수와 길이를 미리 보여 줌. 다른 트랙도 함께 당겨 싱크를 유지하는 옵션
- **비트 마커**: 음악 파형에서 박자(소리가 갑자기 커지는 순간)를 찾아 마커를 찍고 평균 BPM 표시. 선택한 영상 클립을 박자마다 자르기도 가능
- **사진 슬라이드쇼**: 사진(과 영상)을 재생헤드부터 차례로 놓고 전환·켄 번즈·화면 채우기를 한 번에 적용

### 프로젝트 / 미디어
- 영상·오디오·이미지·LUT(.cube) 가져오기: 파일 선택, 드래그 앤 드롭, 타임라인에 바로 드롭
- 썸네일, 필름스트립, 오디오 파형 자동 생성. 아이콘 보기에서 마우스를 올리면 프레임을 훑어볼 수 있음
- **저장소(폴더)** 만들기·이름 바꾸기·접기, 항목을 끌어다 넣기
- **레이블 색상**(미디어·클립), 타임라인 클립 색에 반영
- 색상 매트, 검정 화면, 조정 레이어, 텍스트, 도형(사각형·타원·삼각형·선, 그라디언트)
- 미디어 오프라인 표시와 다시 연결(파일 이름 기준 일괄 연결)
- **자동 저장**: 프로젝트와 가져온 파일을 브라우저 IndexedDB에 저장. 프로젝트 파일(`.json`) 저장/열기

### 시퀀스 / 타임라인
- 여러 시퀀스(탭), 시퀀스 설정(해상도 프리셋·프레임레이트), 복제·삭제
- **자동 리프레임**: 세로 9:16·정사각형·4:5 복사본을 만들고 영상이 화면을 채우도록 확대(가운데 기준)
- 중첩(Nest), 비디오/오디오 트랙 추가·삭제, 잠금, 숨기기, 음소거/솔로, 트랙 볼륨, 대상 트랙
- 도구: 선택(V), 앞쪽 트랙 선택(A), 잔물결 편집(B), 롤링(N), 자르기(C), 슬립(Y), 손(H), 확대(Z), 텍스트(T)
- 덮어쓰기/삽입 이동(Ctrl+끌기), 복제(Alt+끌기), 영역 선택, 스냅, 연결 선택, 연결/해제
- 잔물결 삭제, 빈 공간 메우기, 들어내기/추출(; '), Q/W, Ctrl+K, 1프레임 이동(Alt+←/→)
- 마커, 시퀀스 시작/끝 표시, 원본 프레임 찾기(F), 장면 전환 자동 감지
- 오디오 볼륨 선 끌기, Ctrl+클릭으로 볼륨 키프레임
- 재생헤드를 끌 때 소리 듣기(오디오 스크러빙, 끄고 켤 수 있음)
- 실행 취소/다시 실행(최대 200단계)과 작업 내역 패널

### 효과 컨트롤 / 키프레임
- 기본 효과: 모션, 불투명도와 혼합 모드 17종, **시간 다시 매핑(속도 램프)**, 볼륨, 패너
- 초시계 키프레임, 키프레임 이동, 키프레임 레인에 값 그래프 표시
- **이징 32종**: 직선·부드럽게·정지 + 사인, 2차(Quad), 3차(Cubic), 4차(Quart), 5차(Quint), 지수(Expo), 원형(Circ), 백(Back, 살짝 넘침), 엘라스틱(Elastic, 출렁임), 바운스(Bounce, 통통 튐) 각각 In / Out / In-Out. 키프레임 오른쪽 클릭(또는 값 줄의 곡선 버튼) 메뉴에서 곡선 모양을 보고 고르며, 한 값의 모든 키프레임·클립 전체에 한꺼번에 적용하거나 새 키프레임의 기본 이징으로 정할 수 있음. 이징은 "이 키프레임 → 다음 키프레임" 구간에 쓰임
- **효과 프리셋**: 효과 머리글 오른쪽 클릭 ▸ 프리셋으로 저장 → 효과 패널 ▸ 사용자 프리셋에서 끌어다 적용(이 브라우저에만 저장)

### 색상
- **고급 색상 보정**: 노출·대비·밝은/어두운 영역·흰색/검정 계열·색온도·틴트·채도·생동감, **색상 휠 3개**(어두운/중간/밝은 영역), **RGB 커브**(전체·R·G·B, 점 추가/이동/삭제). WebGL2로 처리
- **LUT 적용(.cube)**: 3D/1D LUT, 강도 조절
- 기본 색상 보정, 밝기/대비, 색조 회전, 틴트, 흑백, 세피아, 반전

### 마스크 / 합성

- **속도 램프**: 시간 다시 매핑 키프레임, "슬로모션 구간 / 빨리 감기 구간" 빠른 설정. 연결된 오디오에도 같은 램프 적용
- 내보내기 오디오: 음 높이 유지(WSOLA 방식 시간 늘이기) 또는 가변 속도(음 높이가 속도를 따라감). 역재생 클립 소리도 미리보기·내보내기에 나옴

- **자동 더킹**: 목소리 트랙의 파형에서 말하는 구간을 찾아 음악 볼륨에 키프레임
- **오디오 추출**: 영상에서 소리만 새 파일로 만들기 — 파일 전체, 소스 시작~끝 표시 구간, 또는 타임라인 클립이 쓰는 부분. WAV / M4A(AAC) / Ogg(Opus), 원본과 같은 형식이면 다시 압축하지 않고 복사. 프로젝트에 추가하거나 파일로 저장하고, 원래 클립 위치에 맞춰 빈 오디오 트랙에 놓을 수도 있음(프로젝트 패널·타임라인 클립 오른쪽 클릭, 클립 메뉴)

- **자동 자막(음성 인식)**: 브라우저 안에서 Whisper 모델(transformers.js) 실행, 또는 Gemini(API 키 필요). 한국어 등 7개 언어, 자막 길이 나누기, **괄호 속 소리 설명 빼기**((음악), [박수]처럼 말이 아닌 괄호 글자 — Whisper가 외침이나 음악 구간에서 지어내기도 함) — 아래 제한 참고

## 알려진 제한 (정직하게)
- 휴대폰 화면은 실제 Android 휴대폰(Chrome, GitHub Pages)에서 열리는 것을 사용자 화면으로 확인했습니다. 화상 키보드가 올라올 때의 동작은 Chromium 에뮬레이션(화면 높이를 줄여 흉내)으로만 확인했습니다
- AI 전체 편집의 결과 품질(어디를 자르고 무엇을 강조하는지)은 Gemini의 판단에 달려 있고, 실제 Gemini로는 시험하지 못했습니다. 영상 화면은 보지 않으므로 자막 내용이 없거나 부정확하면 엉뚱하게 자를 수 있습니다(실행 취소 한 번으로 되돌리기)
- **Gemini 기능은 실제 Gemini 서버로 시험하지 못했습니다.** 개발 환경에 API 키가 없어, 가짜(모의) 서버 응답으로 요청 형식·도구 실행·오류 처리·실행 취소만 확인했습니다. 요청 형식은 공개 문서 검색 결과를 바탕으로 했고, 브라우저에서 직접 호출이 허용되는지(CORS)는 확인했습니다. 실제 모델이 도구를 얼마나 잘 고르는지, 자막 시간 위치가 얼마나 정확한지는 확인하지 못했습니다
- claude.ai 아티팩트 보기 화면에서는 외부 연결이 막혀 Gemini를 쓸 수 없습니다. GitHub Pages 주소나 내 컴퓨터에서 여세요
- Gemini API 사용량에 따라 요금이나 무료 한도가 적용됩니다. Gemini API 약관상 무료 등급에서 보낸 내용은 Google이 서비스 개선에 쓰고 사람이 검토할 수 있다고 되어 있습니다(약관은 바뀔 수 있으니 원문 확인 권장)
- **휴대폰 화면은 실제 휴대폰에서 시험하지 못했습니다.** 개발 환경의 Chromium에서 Pixel 7(세로·가로)·iPhone 13 크기로 흉내 내고, 손가락 조작은 가짜 터치 이벤트로만 확인했습니다. 특히 **iPhone/iPad Safari는 시험하지 않았고**, WebCodecs·AudioWorklet 지원 정도에 따라 일부 기능(내보내기 등)이 동작하지 않을 수 있습니다(확실하지 않음). 휴대폰은 메모리가 작아 긴 영상이나 고해상도 내보내기에서 멈추거나 느릴 수 있습니다
- 무음 구간 삭제와 비트 마커는 파형의 크기만 봅니다. 배경 소음이 큰 녹음, 박자가 또렷하지 않은 곡에서는 잘 맞지 않을 수 있습니다(값을 조절하거나 실행 취소)
- "계속 움직이기" 애니메이션은 같은 값(크기·위치·회전)의 등장/퇴장 움직임을 덮어씁니다. 함께 쓰려면 계속 움직이기를 먼저 넣으세요
- **자동 자막은 실제 모델로 시험하지 못했습니다.** 개발 환경에서 jsdelivr·huggingface.co 다운로드가 막혀 있었습니다. 처음 쓸 때 라이브러리와 모델(약 40~250MB)을 인터넷에서 받아야 하며, claude.ai 아티팩트 보기 화면처럼 외부 다운로드가 막힌 곳에서는 작동하지 않습니다
- 보이스오버 녹음은 마이크 권한이 필요합니다. claude.ai 아티팩트 보기 화면에서는 마이크가 막혀 있어 쓸 수 없습니다(테스트는 Chromium 가짜 마이크로 함)
- 손떨림 보정은 화면 전체의 이동·회전만 추정하는 단순한 방식입니다. 원근 왜곡이나 롤링 셔터는 보정하지 못합니다
- 자동 리프레임은 가운데 기준으로 자릅니다. 피사체를 따라가지 않습니다
- 미리보기는 `<video>` 요소 동기화 방식이라 복잡한 타임라인에서 프레임이 빠질 수 있습니다. 내보내기는 프레임 단위로 정확합니다. 미리보기의 속도 램프 소리는 근사치입니다
- 아주 긴 4K 프로젝트는 브라우저 메모리와 속도 한계에 걸릴 수 있습니다
- M4A(AAC) 만들기는 브라우저에 AAC 인코더가 있어야 합니다. 개발 환경의 Chromium에는 없어 **시험하지 못했고**, 없으면 메뉴에 "사용 불가"로 표시됩니다. MP3로 저장하는 기능은 없습니다
- Pretendard, 나눔스퀘어 등 Google Fonts에 없는 글꼴은 목록에 없습니다. 글꼴 파일을 받아 "글꼴 파일 가져오기"로 넣으면 쓸 수 있습니다
- 브라우저가 예약한 단축키(Ctrl+N, Ctrl+T, Ctrl+W 등)는 쓸 수 없어 메뉴로 대신합니다
- 프로젝트 파일에는 미디어가 들어가지 않습니다. 다른 컴퓨터에서는 "미디어 다시 연결"이 필요합니다
