# Montage — 브라우저 영상·사진 편집기

Premiere Pro의 작업 방식(프로젝트 패널 → 소스/프로그램 모니터 → 멀티트랙 타임라인 → 효과 컨트롤 → 내보내기)을 본뜬 **브라우저 기반 비선형 영상 편집기(NLE)**와, Photoshop의 작업 방식(도구 상자 → 옵션 막대 → 레이어·마스크 → 조정·필터)을 본뜬 **사진 편집기**가 한 프로그램에 들어 있습니다. 위 막대의 **영상 편집 / 사진 편집** 버튼(휴대폰은 **영상 / 사진**)으로 오갑니다. 화면은 모두 한국어이고, 설치나 서버 없이 브라우저 안에서만 동작합니다. 미디어 파일은 사용자 컴퓨터 밖으로 나가지 않습니다(자동 자막의 모델 다운로드만 예외, 아래 참고).

> Adobe와 무관한 독립 구현입니다. Adobe 코드·디자인·상표를 사용하지 않았고, 단축키와 패널 구성 같은 작업 흐름만 참고했습니다. Premiere Pro나 Photoshop의 모든 기능을 갖춘 복제품은 아닙니다(아래 "알려진 제한" 참고).

## 실행 방법

ES 모듈을 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 정적 웹 서버로 열어야 합니다.

```bash
# 저장소 루트에서 아래 중 하나
python3 -m http.server 8000
npx serve .
```

브라우저에서 `http://localhost:8000` 을 엽니다. 빌드 단계는 없습니다.

## 웹사이트와 편집기

저장소 루트는 웹사이트이고, 편집기는 `app.html`에 있습니다.

| 주소 | 내용 |
| --- | --- |
| `index.html` | 홈: 두 편집기 소개, AI 편집, 파일이 나가지 않는 방식, 휴대폰 화면, 설명서 검색, 알려진 제한 |
| `video.html` | 영상 편집 기능: 설명서의 영상·AI 쪽마다 한 묶음씩 (설명서 내용에서 바로 만들어서 항상 같음) |
| `photo.html` | 사진 편집 기능: 설명서의 사진 쪽마다 한 묶음씩 |
| `docs.html` | 설명서 64쪽을 웹 페이지로: 목차, 검색, 이 쪽의 내용, 이전/다음. `docs.html#쪽-이름`, `docs.html?q=검색어` |
| `app.html` | 편집기. 처음 열면 샘플 프로젝트와 **시작 가이드**가 나옵니다(`?blank` 빈 프로젝트, `?mode=photo` / `?mode=video` 시작 편집기) |

- 모든 쪽 위의 메뉴: 홈 · 영상 편집 · 사진 편집 · 설명서, 밝게/어둡게, **편집기 열기**(영상 / 사진). 휴대폰에서는 ☰ 메뉴로 접힙니다.
- 예전 주소는 그대로 이어집니다: 루트에 `?blank`나 `?mode=…`가 붙으면 `app.html`로, `#docs/쪽-이름`이 붙으면 `docs.html#쪽-이름`으로 넘어갑니다.
- 편집기 안의 **설명서** 버튼은 지금처럼 편집기 위에 겹쳐 열리고, **도움말 ▸ Montage 웹사이트**는 새 탭으로 웹사이트를 엽니다. 마지막으로 쓴 편집기(영상/사진)는 기억했다가 `app.html`을 열면 그 화면으로 엽니다.
- 웹사이트의 화면 사진(`site/img/`)은 이 편집기를 실제로 실행해 찍은 것입니다. 글꼴은 Google Fonts에서 불러옵니다.

**권장 브라우저:** 최신 Chrome / Edge. WebCodecs, Canvas `filter`, WebGL/WebGL2, AudioWorklet을 사용합니다.
- MP4(H.264/AAC) 디코딩·인코딩은 브라우저 코덱 지원에 따라 달라집니다. H.264를 지원하지 않는 브라우저(예: 일부 Linux 빌드의 Chromium)에서는 WebM으로 내보내면 됩니다. 개발 환경의 Chromium에는 H.264 인코더가 없어 **MP4 내보내기 경로는 직접 시험하지 못했습니다.**
- Firefox와 Safari는 테스트하지 않았습니다.

## 보기 쉽게 쓰기
- **창 ▸ 화면 크기**(영상 편집): 작게 / 보통 / 크게 / 아주 크게 (글자·버튼·타임라인 글씨가 함께 커짐)
- **창 ▸ 작업 영역**(Alt+Shift+1~9): 학습, 어셈블리, 편집, 색상, 효과, 오디오, 그래픽, 캡션 및 그래픽, 멀티 카메라, 검토. 내 배치 저장, 저장된 레이아웃으로 재설정
- 버튼은 아이콘 + 한국어 설명(마우스를 올리면 단축키 표시), 대화상자는 쉬운 말 위주
- **설명서**(위 막대의 설명서 버튼, 도움말 ▸ 설명서): 모든 기능을 64쪽으로 정리한 앱 안 설명서. 왼쪽 목차, 검색(`/`), 이 쪽의 내용, 이전/다음, 밝게/어둡게. 주소 끝에 `#docs/쪽-이름`을 붙이면 그 쪽으로 바로 열림
- **도움말 ▸ 시작 가이드**, **키보드 단축키(F1)**: 영상 편집은 메뉴 명령마다 내 단축키를 정할 수 있음(편집 ▸ 키보드 단축키…)

## 휴대폰에서 쓰기
폭이 좁은 화면(760px 이하)이나 가로로 눕힌 휴대폰에서는 **휴대폰 화면 배치**로 바뀝니다. 같은 프로젝트와 기능을 그대로 쓰고, 화면만 손가락에 맞게 바뀝니다.
- 세로: 위에 미리보기, 가운데 타임라인, 아래에 도구 막대. 가로: 왼쪽 미리보기, 오른쪽 타임라인
- **＋ 버튼**: 영상·사진·음악을 골라 재생헤드 위치에 차례로 넣기. 미디어 목록의 "넣기" 버튼도 같은 일
- **아래 도구 막대**: 미디어, 텍스트, 스티커, 애니메이션, 필터, 효과, 소리, 화면, 자동 편집, 조정, 더보기. 누르면 아래(가로일 때는 오른쪽)에서 시트가 올라오고, 손잡이를 누르면 크게/작게
- **클립 도구 막대**(클립을 고르면 나타남): 분할, 삭제(빈자리 당김), 복제, 속도, 역재생, 정지 화면, 애니메이션, 필터, 위치·크기, 소리, 세부 조정, 선택 해제
- 타임라인 손가락 조작: 끌어서 이동, 두 손가락 벌리기/오므리기로 확대/축소, 탭으로 클립 선택(빈 곳은 재생헤드 이동), 선택한 클립은 끌어서 옮기거나 양쪽 끝 손잡이로 길이 조절, 길게 누르면 클립 메뉴
- 미리보기 손가락 조작: 선택한 클립을 끌어서 옮기기, 두 손가락으로 크기(벌리기)·회전(비틀기, 90°마다 살짝 붙음)·위치 바꾸기
- 위 막대의 ☰ 버튼으로 데스크톱의 전체 메뉴를 모두 쓸 수 있음. 대화상자는 아래에서 올라오는 시트로 표시
- 세로 화면의 시트는 미리보기와 재생 버튼 바로 아래부터 열려, 시트를 연 채로 재생할 수 있음. 시트 안에서 글자를 입력하면(키보드가 올라오면) 시트가 화면 전체로 커져 입력 칸이 가려지지 않음

## 사진 편집 (Photoshop 방식)
위 막대의 **사진 편집**을 누르면 화면 전체가 사진 편집기로 바뀝니다(메뉴도 Photoshop 순서대로 파일·편집·이미지·레이어·문자·선택·필터·AI·보기·창·도움말로 바뀜). 사진 편집기는 처음 누를 때 불러오므로 영상 편집기만 쓸 때는 느려지지 않습니다.

- **문서**: 새로 만들기(유튜브 1920×1080, 쇼츠 1080×1920, 인스타, 썸네일, A4 등 프리셋, 배경 흰색·투명·전경색 등), 여러 문서를 탭으로 열기, 사진·PSD·`.mphoto` 열기(파일을 끌어 놓기, Shift를 누른 채 놓으면 새 레이어로), 다른 프로그램에서 복사한 이미지 붙여넣기(Ctrl+V)
- **도구 67개**(Photoshop처럼 칸마다 묶임): 이동, 선택 윤곽 4종, 올가미 3종, 개체 선택·빠른 선택·마술봉, 자르기·원근 자르기, 스포이드·색상 샘플러·눈금자·메모·카운트, 복구 6종(스팟 복구·복구·패치·내용 인식 이동·제거·적목), 브러시·연필·색상 대체·혼합 브러시, 복제 도장·패턴 도장, 작업 내역 브러시·**미술 작업 내역 브러시**, 지우개 3종, 그레이디언트·페인트 통, 흐림·선명·손가락·픽셀 밀기, 닷지·번·**스폰지**, 펜 6종(곡률 펜 포함), 문자 4종, 패스 선택·직접 선택, 모양 6종(사각형·타원·삼각형·다각형·선·사용자 정의 모양 76가지), **프레임**(K, 사진을 넣는 모양 틀), 손, **회전 보기**(R, 화면만 돌리기), 돋보기. 브러시·연필·지우개는 **대칭 칠하기**(좌우·위아래·네 방향·방사형·만다라). 같은 칸의 도구는 오른쪽 클릭(휴대폰은 길게 누르기)이나 Shift+단축키로 바꿈
- **브러시 엔진**: **브러시** 패널(사전 설정 그룹), **브러시 설정** 패널(F5: 브러시 모양, 모양, 분산, 텍스처, 이중 브러시, 색상, 전송, 노이즈, 젖은 가장자리, 효과 쌓기, 보정), 펜 압력, 오른쪽 클릭 브러시 피커, 편집 ▸ 브러시 사전 설정 정의. 편집 ▸ 사전 설정에서 Photoshop **.abr 브러시·.pat 패턴·.grd 그레이디언트 가져오기**. 색상 피커, 그레이디언트 편집기(노이즈 그레이디언트 포함), 복제 원본 패널
- **복구·리터치 도구**: 스팟 복구 브러시(기본 **내용 인식**, 예전 방식은 근접 일치), **복구 브러시**(Alt+클릭 원본, 칠한 뒤 경계 색을 주변에 맞춤), **패치**(올가미로 감싸고 끌기, 원본/대상), **내용 인식 이동**(이동/확장, 빈자리는 주변으로 채움), **제거 도구**(칠한 곳을 주변 무늬로 다시 만듦), **적목 현상**(누르거나 눈을 감싸 끌기), **혼합 브러시**(젖음·물감 양·섞기·획마다 붓 씻기), **작업 내역 브러시**(Y, 작업 내역 패널의 붓 표시로 원본 시점 고르기), **색상 대체**(색상·색조·채도·광도), **배경 지우개**(허용치·샘플링·인접·전경색 보호), **자동 지우개**, 편집 ▸ **내용 인식 채우기**(칠 대화상자에도 있음)
- **재기·표시 도구**(스포이드 칸): **색상 샘플러**(10곳까지 RGB 표시, 끌어서 옮기기, Alt+클릭 지우기), **눈금자**(길이·각도, **레이어 똑바르게**), **메모**, **카운트**(색 5가지, Alt+클릭 빼기). 메모·카운트·샘플러는 `.mphoto`에 저장
- **레이어**: 일반(픽셀)·글자·모양·조정 레이어, 보이기/숨기기, 불투명도, **혼합 모드 27종**(곱하기·스크린·오버레이·소프트 라이트·차이·색상·광도 등, 그룹은 통과), 그룹·클리핑 마스크, **레이어 찾기**(이름·종류로 거르기), 숨긴 레이어 삭제, **배경 제거**(피사체만 남기는 마스크), 잠금·투명 픽셀 잠금, 끌어서 순서 바꾸기, 복제, 복사한/잘라낸 레이어(선택 영역), 아래로 병합, 보이는 레이어 병합, 이미지 병합, 래스터화, 축소판 Ctrl+클릭으로 모양대로 선택
- **레이어 마스크**: 모두 나타내기(선택 영역이 있으면 그 부분만)·모두 숨기기, 마스크 축소판을 누르고 검정/흰색으로 칠하기, 반전·끄기·적용·삭제
- **레이어 스타일 10종**: 드롭 섀도·내부 그림자, 외부·내부 광선, 경사와 엠보스(윤곽선·텍스처), 새틴, 색상·그레이디언트·패턴 오버레이, 획. 획·그림자·오버레이는 여러 겹, 전체 조명, 효과 비율 조정. **혼합 옵션**: 칠 불투명도, 채널 R·G·B, 녹아웃, 혼합 조건(밝기로 보이기)
- **프레임**(프레임 도구 K): 사각형·원·하트 등 모양 틀을 그리고 사진 파일을 끌어 놓으면 틀을 채우는 고급 개체로 들어감(캔바의 프레임처럼). 프레임을 끌면 사진도 함께 움직임
- **타임라인(움직이는 GIF)**: 프레임마다 레이어 보이기·위치·불투명도를 다르게, 트윈(사이 프레임), 레이어로 프레임 만들기, 재생, **애니메이션 GIF 내보내기**. `.mphoto`에 저장

## 영상 편집 기능

### AI 편집 (Gemini, 메뉴 AI ▸ / 창 ▸ AI 편집)
본인의 **Gemini API 키**(Google AI Studio에서 발급)를 넣으면 브라우저가 Google Gemini API에 직접 연결합니다. 이 편집기에는 따로 서버가 없습니다.
- **AI로 전체 편집하기** (AI 탭 ▸ 전체 편집): 스타일(브이로그·쇼츠·정보·감성 여행·예능)과 목표 길이를 고르고 시작하면 차례로 — 화면 비율(쇼츠는 9:16로 바꾸고 화면 채우기) → 말 없는 구간 잘라내기 → 자막 만들기(없을 때) → **Gemini가 자막을 읽고** 말 실수·덜 중요한 부분 잘라 길이 맞추기, 오프닝 제목, 강조 문구·스티커, 챕터 마커, 맞춤법 → 컷 사이 전환과 처음·끝 페이드 → 색 필터 → 자막 모양 → 배경음악(말할 때 줄이기, 끝에 맞춰 자르고 페이드 아웃). 배경음악은 자르지 않고 이어서 깔림. 할 일을 하나씩 끄고 켤 수 있고, 진행 상황이 단계마다 보이며, 전체가 **실행 취소 한 번**으로 되돌아감. Gemini 키가 없으면 자막은 Whisper로 만들고 내용 편집은 건너뜀(프로젝트 이름으로 제목만)
- **AI 편집 도우미**: "앞 3초 잘라 줘", "자막 맞춤법 고쳐 줘", "30초 하이라이트 만들어 줘"처럼 말로 요청하면 Gemini가 편집 도구를 골라 실행합니다. 쓸 수 있는 도구: 구간 잘라내기(빈자리 당김), 클립 지우기, 분할, 자막·글자 고치기, 자막 트랙 추가(번역 등), 제목 넣기, 마커, 필터, 애니메이션, 볼륨, 속도, 전환, 스티커, 화면 비율, 재생헤드 이동. 요청 한 번의 편집은 **실행 취소 한 번**으로 모두 되돌아감. 자주 쓰는 요청 버튼(맞춤법, 말 실수 잘라내기, 하이라이트, 마커, 영어 자막, 제목·설명·해시태그, 강조 문구, 쇼츠로 바꾸기)
- **AI가 영상 화면 보기 (장면 사진)**: 설정에서 켜면 몇 초마다(1·2·3·5·10초, 기본 2초) 타임라인 화면을 작은 사진(384px 이하 JPEG, 최대 150장)으로 찍어 시간과 함께 보냅니다. 말이 없는 장면도 보고 고르고("고양이 나오는 장면만"), 흔들리거나 어둡거나 아무것도 안 나오는 구간을 빼고, 화면에 맞는 제목을 붙일 수 있습니다. 기본값은 "전체 편집할 때만"이고, "도우미 대화마다" 또는 "보내지 않기"로 바꿀 수 있습니다. 시간 정확도는 사진 간격 정도(1~2초)입니다
- 소리는 직접 듣지 않습니다. 말 내용은 자막으로 판단하므로, 말이 중요한 영상은 자막이 있어야 제대로 됩니다
- **대본으로 편집**: 자막을 한 줄씩 보며 글자를 고치고, 찾아 바꾸기, 체크한 줄을 **자막만 지우기**(잘못 받아 적은 줄) 또는 **영상에서 잘라내기**(그 말을 한 구간을 모든 트랙에서 잘라 냄, 텍스트 기반 편집). 이 기능은 키 없이 씁니다
- **Gemini 자동 자막**: 자동 자막 창에서 엔진을 Gemini로 고르면 섞인 소리를 3분씩 나눠 Gemini로 보내 받아 적습니다
- 모델은 키로 쓸 수 있는 목록을 불러와 고르고, 고르지 않으면 가장 알맞은 안정판 Flash 모델을 자동으로 씁니다. 키는 기본적으로 탭을 닫으면 지워지고, "이 브라우저에 기억하기"를 켜면 이 브라우저에 저장됩니다

- 소스 범위, 프레임 크기·속도(23.976 등), 비트레이트(화질 기준·VBR·CBR), 키프레임 간격, 최대 렌더링 품질, 음량 정규화(LUFS·트루 피크), 예상 파일 크기
- 프레임 내보내기(Ctrl+Shift+E, PNG·JPEG)

## 알려진 제한 (정직하게)
- **사진 편집은 Photoshop의 일부 기능만 흉내 냅니다.** 없는 것: CMYK·16비트(8비트 RGB만), RAW 현상, 대지(아트보드), Camera Raw의 마스킹 패널, 비선형 작업 내역. 내용 인식 채우기·제거·패치는 직접 만든 계산(PatchMatch)이라 Photoshop(AI 포함)과 결과가 다르고, 아주 큰 영역(400×400 픽셀 이상)은 몇 초 걸립니다. 필터와 조정도 직접 만든 간단한 계산이라 같은 값이라도 Photoshop과 결과가 다릅니다
- **PSD는 실제 Photoshop에서 만든 파일로 시험하지 못했습니다.** 개발 환경에 Photoshop 파일이 없어, 같은 PSD 라이브러리(ag-psd)로 만든 파일과 이 프로그램이 저장한 파일을 다시 여는 것으로만 확인했습니다. 그룹, 레이어 스타일, 혼합 옵션, 대부분의 조정 레이어는 열고 저장할 때 유지됩니다. 열 때 글자 레이어는 고칠 수 있는 글자로, 고급 필터가 있는 고급 개체는 이미지로 열리고, PSD 안의 패턴은 기본 패턴으로 바뀌며 색상 검색 조정 레이어는 빠집니다. 기본 "PSD로 저장"은 글자·모양을 픽셀로 저장하고, "글자·모양을 포토샵에서 고칠 수 있게(실험적)"는 글자를 기본 서식 하나로만 저장합니다. 모든 것을 고칠 수 있게 보관하려면 `.mphoto`로 저장하세요
- 사진 편집의 브라우저 예약 단축키(Ctrl+N 새 문서, Ctrl+T 자유 변형, Ctrl+W, Ctrl+Tab)는 Chrome이 먼저 가져가므로 메뉴를 쓰세요(문서 바꾸기는 Ctrl+F6)
- 아주 큰 사진은 브라우저 메모리 때문에 느리거나 멈출 수 있습니다(어느 크기부터인지는 시험하지 않았습니다). 새 문서는 8000만 픽셀까지만 만들 수 있게 막아 두었습니다
- 사진 편집의 휴대폰 화면과 손가락 조작(칠하기·두 손가락 확대)은 Chromium 에뮬레이션(411×756, 가짜 터치 이벤트)으로만 시험했습니다
- 휴대폰 화면은 실제 Android 휴대폰(Chrome, GitHub Pages)에서 열리는 것을 사용자 화면으로 확인했습니다. 화상 키보드가 올라올 때의 동작은 Chromium 에뮬레이션(화면 높이를 줄여 흉내)으로만 확인했습니다
- AI 전체 편집의 결과 품질(어디를 자르고 무엇을 강조하는지)은 Gemini의 판단에 달려 있고, 실제 Gemini로는 시험하지 못했습니다. 자막이나 장면 사진이 부정확하거나 없으면 엉뚱하게 자를 수 있습니다(실행 취소 한 번으로 되돌리기)
- 장면 사진을 켜면 영상 화면이 Google로 보내지고, 사진 수만큼 사용량(요금·무료 한도)이 늘어납니다. Gemini와 여러 차례 주고받는 요청은 그때마다 사진을 다시 보냅니다. 사진을 찍는 데도 시간이 걸립니다(개발 환경 기준 1080p 영상에서 한 장에 약 0.25초)
- **Gemini 기능(영상·사진 모두, 사진의 생성형 채우기 포함)은 실제 Gemini 서버로 시험하지 못했습니다.** 개발 환경에 API 키가 없어, 가짜(모의) 서버 응답으로 요청 형식·도구 실행·오류 처리·실행 취소만 확인했습니다. 요청 형식은 공개 문서 검색 결과를 바탕으로 했고, 브라우저에서 직접 호출이 허용되는지(CORS)는 확인했습니다. 실제 모델이 도구를 얼마나 잘 고르는지, 자막 시간 위치가 얼마나 정확한지는 확인하지 못했습니다
- claude.ai 아티팩트 보기 화면에서는 외부 연결이 막혀 Gemini를 쓸 수 없습니다. GitHub Pages 주소나 내 컴퓨터에서 여세요
- Gemini API 사용량에 따라 요금이나 무료 한도가 적용됩니다. Gemini API 약관상 무료 등급에서 보낸 내용은 Google이 서비스 개선에 쓰고 사람이 검토할 수 있다고 되어 있습니다(약관은 바뀔 수 있으니 원문 확인 권장)
- **휴대폰 화면은 실제 휴대폰에서 시험하지 못했습니다.** 개발 환경의 Chromium에서 Pixel 7(세로·가로)·iPhone 13 크기로 흉내 내고, 손가락 조작은 가짜 터치 이벤트로만 확인했습니다. 특히 **iPhone/iPad Safari는 시험하지 않았고**, WebCodecs·AudioWorklet 지원 정도에 따라 일부 기능(내보내기 등)이 동작하지 않을 수 있습니다(확실하지 않음). 휴대폰은 메모리가 작아 긴 영상이나 고해상도 내보내기에서 멈추거나 느릴 수 있습니다
- 무음 구간 삭제와 비트 마커는 파형의 크기만 봅니다. 배경 소음이 큰 녹음, 박자가 또렷하지 않은 곡에서는 잘 맞지 않을 수 있습니다(값을 조절하거나 실행 취소)
- "계속 움직이기" 애니메이션은 같은 값(크기·위치·회전)의 등장/퇴장 움직임을 덮어씁니다. 함께 쓰려면 계속 움직이기를 먼저 넣으세요
- **자동 자막은 실제 모델로 시험하지 못했습니다.** 개발 환경에서 jsdelivr·huggingface.co 다운로드가 막혀 있었습니다. 처음 쓸 때 라이브러리와 모델(약 40~250MB)을 인터넷에서 받아야 하며, claude.ai 아티팩트 보기 화면처럼 외부 다운로드가 막힌 곳에서는 작동하지 않습니다
- 보이스오버 녹음은 마이크 권한이 필요합니다. claude.ai 아티팩트 보기 화면에서는 마이크가 막혀 있어 쓸 수 없습니다(테스트는 Chromium 가짜 마이크로 함)
- 워프 안정기(손떨림 보정)는 화면 전체의 이동·회전만 추정하는 단순한 방식입니다. 원근 왜곡이나 롤링 셔터는 보정하지 못합니다. 마스크 추적도 단순한 비교 방식이라 느리고(한 프레임에 약 0.3초), 빠른 움직임은 놓칠 수 있습니다
- 대부분의 새 비디오 효과·전환과 키잉, 효과 마스크는 WebGL2가 필요합니다(없으면 효과가 빠지고 전환은 교차 디졸브로 대신함). Premiere와 다른 점: 위치의 공간 보간 없음, 오디오 트랙 믹서의 자동화 모드·센드 없음, Lumetri 범위의 HDR·색 공간 설정 없음, 기본 그래픽의 반응형 디자인 - 위치 없음, 내 단축키는 메뉴 명령에만
- 자동 리프레임은 가운데 기준으로 자릅니다. 피사체를 따라가지 않습니다
- 미리보기는 `<video>` 요소 동기화 방식이라 복잡한 타임라인에서 프레임이 빠질 수 있습니다. 내보내기는 프레임 단위로 정확합니다. 미리보기의 속도 램프 소리는 근사치입니다
- 아주 긴 4K 프로젝트는 브라우저 메모리와 속도 한계에 걸릴 수 있습니다
- M4A(AAC)와 HEVC 만들기는 브라우저에 인코더가 있어야 합니다. 개발 환경의 Chromium에는 없어 **시험하지 못했고**, 없으면 고를 수 없게 표시됩니다. MP3로 저장하는 기능은 없습니다
- 내보낼 때 소리 전체를 한 번에 섞으므로 아주 긴 프로젝트(약 1시간 이상, 휴대폰은 더 짧게)는 메모리가 모자랄 수 있습니다
- Pretendard, 나눔스퀘어 등 Google Fonts에 없는 글꼴은 목록에 없습니다. 글꼴 파일을 받아 "글꼴 파일 가져오기"로 넣으면 쓸 수 있습니다
- 브라우저가 예약한 단축키(Ctrl+N, Ctrl+T, Ctrl+W 등)는 쓸 수 없어 메뉴로 대신합니다
- 프로젝트 파일에는 미디어가 들어가지 않습니다. 다른 컴퓨터에서는 "파일 ▸ 미디어 연결"이 필요합니다

`vendor/mediabunny/`는 [mediabunny](https://github.com/Vanilagy/mediabunny)(MPL-2.0)를 수정하지 않고 그대로 포함한 것입니다. 라이선스 전문은 같은 폴더에 있습니다. `vendor/ag-psd/`는 [ag-psd](https://github.com/Agamnentzar/ag-psd) 31.0.2(MIT)와 그것이 쓰는 pako·base64-js(MIT)를 브라우저용 파일 하나로 묶은 것이며, 라이선스 전문은 같은 폴더의 `LICENSE.txt`에 있습니다. 자동 자막은 실행 시 [transformers.js](https://github.com/huggingface/transformers.js)(Apache-2.0)와 Whisper 모델을 CDN에서 불러오며 저장소에는 포함하지 않습니다.
