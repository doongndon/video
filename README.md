# Montage — 브라우저 영상 편집기

Premiere Pro의 작업 방식(프로젝트 패널 → 소스/프로그램 모니터 → 멀티트랙 타임라인 → 효과 컨트롤 → 내보내기)을 본뜬 **브라우저 기반 비선형 영상 편집기(NLE)**입니다. 화면은 모두 한국어이고, 설치나 서버 없이 브라우저 안에서만 동작합니다. 미디어 파일은 사용자 컴퓨터 밖으로 나가지 않습니다(자동 자막의 모델 다운로드만 예외, 아래 참고).

> Adobe와 무관한 독립 구현입니다. Adobe 코드·디자인·상표를 사용하지 않았고, 단축키와 패널 구성 같은 작업 흐름만 참고했습니다. Premiere Pro의 모든 기능을 갖춘 복제품은 아닙니다(아래 "알려진 제한" 참고).

## 실행 방법

ES 모듈을 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 정적 웹 서버로 열어야 합니다.

```bash
# 저장소 루트에서 아래 중 하나
python3 -m http.server 8000
npx serve .
```

브라우저에서 `http://localhost:8000` 을 엽니다. 빌드 단계는 없습니다. 처음 열면 샘플 프로젝트와 **시작 가이드**가 나옵니다(`?blank`를 붙이면 빈 프로젝트로 시작).

**권장 브라우저:** 최신 Chrome / Edge. WebCodecs, Canvas `filter`, WebGL/WebGL2, AudioWorklet을 사용합니다.
- MP4(H.264/AAC) 디코딩·인코딩은 브라우저 코덱 지원에 따라 달라집니다. H.264를 지원하지 않는 브라우저(예: 일부 Linux 빌드의 Chromium)에서는 WebM으로 내보내면 됩니다. 개발 환경의 Chromium에는 H.264 인코더가 없어 **MP4 내보내기 경로는 직접 시험하지 못했습니다.**
- Firefox와 Safari는 테스트하지 않았습니다.

## 보기 쉽게 쓰기
- **보기 ▸ 화면 크기**: 작게 / 보통 / 크게 / 아주 크게 (글자·버튼·타임라인 글씨가 함께 커짐)
- **창 ▸ 작업 영역**: 편집, 색상 보정, 오디오, 효과, 자막·그래픽, 멀티캠, 검토(모니터 크게) 배치
- 버튼은 아이콘 + 한국어 설명(마우스를 올리면 단축키 표시), 대화상자는 쉬운 말 위주
- **도움말 ▸ 시작 가이드**, **단축키 목록(F1)**

## 기능

### 프로젝트 / 미디어
- 영상·오디오·이미지·LUT(.cube) 가져오기: 파일 선택, 드래그 앤 드롭, 타임라인에 바로 드롭
- 썸네일, 필름스트립, 오디오 파형 자동 생성. 아이콘 보기에서 마우스를 올리면 프레임을 훑어볼 수 있음
- **저장소(폴더)** 만들기·이름 바꾸기·접기, 항목을 끌어다 넣기
- **레이블 색상**(미디어·클립), 타임라인 클립 색에 반영
- 색상 매트, 검정 화면, 조정 레이어, 텍스트, 도형(사각형·타원·삼각형·선, 그라디언트)
- 미디어 오프라인 표시와 다시 연결(파일 이름 기준 일괄 연결)
- **자동 저장**: 프로젝트와 가져온 파일을 브라우저 IndexedDB에 저장. 프로젝트 파일(`.json`) 저장/열기

### 시퀀스 / 타임라인
- 여러 시퀀스(탭), 시퀀스 설정(해상도 프리셋·프레임레이트), 복제·삭제
- **자동 리프레임**: 세로 9:16·정사각형·4:5 복사본을 만들고 영상이 화면을 채우도록 확대(가운데 기준)
- 중첩(Nest), 비디오/오디오 트랙 추가·삭제, 잠금, 숨기기, 음소거/솔로, 트랙 볼륨, 대상 트랙
- 도구: 선택(V), 앞쪽 트랙 선택(A), 잔물결 편집(B), 롤링(N), 자르기(C), 슬립(Y), 손(H), 확대(Z), 텍스트(T)
- 덮어쓰기/삽입 이동(Ctrl+끌기), 복제(Alt+끌기), 영역 선택, 스냅, 연결 선택, 연결/해제
- 잔물결 삭제, 빈 공간 메우기, 들어내기/추출(; '), Q/W, Ctrl+K, 1프레임 이동(Alt+←/→)
- 마커, 시퀀스 시작/끝 표시, 원본 프레임 찾기(F), 장면 전환 자동 감지
- 오디오 볼륨 선 끌기, Ctrl+클릭으로 볼륨 키프레임
- 재생헤드를 끌 때 소리 듣기(오디오 스크러빙, 끄고 켤 수 있음)
- 실행 취소/다시 실행(최대 200단계)과 작업 내역 패널

### 효과 컨트롤 / 키프레임
- 기본 효과: 모션, 불투명도와 혼합 모드 17종, **시간 다시 매핑(속도 램프)**, 볼륨, 패너
- 초시계 키프레임, 키프레임 이동, 키프레임 레인에 값 그래프 표시
- **이징 32종**: 직선·부드럽게·정지 + 사인, 2차(Quad), 3차(Cubic), 4차(Quart), 5차(Quint), 지수(Expo), 원형(Circ), 백(Back, 살짝 넘침), 엘라스틱(Elastic, 출렁임), 바운스(Bounce, 통통 튐) 각각 In / Out / In-Out. 키프레임 오른쪽 클릭(또는 값 줄의 곡선 버튼) 메뉴에서 곡선 모양을 보고 고르며, 한 값의 모든 키프레임·클립 전체에 한꺼번에 적용하거나 새 키프레임의 기본 이징으로 정할 수 있음. 이징은 "이 키프레임 → 다음 키프레임" 구간에 쓰임
- **효과 프리셋**: 효과 머리글 오른쪽 클릭 ▸ 프리셋으로 저장 → 효과 패널 ▸ 사용자 프리셋에서 끌어다 적용(이 브라우저에만 저장)

### 색상
- **고급 색상 보정**: 노출·대비·밝은/어두운 영역·흰색/검정 계열·색온도·틴트·채도·생동감, **색상 휠 3개**(어두운/중간/밝은 영역), **RGB 커브**(전체·R·G·B, 점 추가/이동/삭제). WebGL2로 처리
- **LUT 적용(.cube)**: 3D/1D LUT, 강도 조절
- 기본 색상 보정, 밝기/대비, 색조 회전, 틴트, 흑백, 세피아, 반전

### 마스크 / 합성
- **마스크**: 타원·사각형·다각형(펜), 페더·확장·불투명도·반전, 위치·크기·회전 키프레임. **프로그램 모니터에서 직접 편집**(가운데 점: 이동, 모서리: 크기, 위 점: 회전, 다각형은 점 끌기 / Ctrl+클릭 점 추가 / Alt+클릭 점 삭제)
- 부분 모자이크/흐림(얼굴 가리기, 모니터에서 영역 편집), 트랙 매트 키(알파/루마), 크로마 키(WebGL)

### 기타 비디오 효과
가우시안 흐림, 선명하게, 가장자리 찾기, 포스터화, 모자이크, 비네팅, 글로우, 필름 그레인, 그림자, 자르기, 뒤집기, 레터박스, 카메라 흔들림, **손떨림 보정**(클립 분석 → 이동·회전 보정, 부드러움·추가 확대)

### 전환
교차 디졸브, 가산 디졸브, 흐림 디졸브, 검정/흰색으로 물들이기, 와이프·밀기·슬라이드·휙 넘기기(방향 선택), 반 도어, 시계 방향 와이프, 원형 아이리스, 교차 확대 · 오디오: 지속 가속, 지속 게인

### 속도
- 속도/지속 시간(25~400% 빠른 선택), 역재생, 프레임 고정, **음 높이 유지** 켜기/끄기
- **속도 램프**: 시간 다시 매핑 키프레임, "슬로모션 구간 / 빨리 감기 구간" 빠른 설정. 연결된 오디오에도 같은 램프 적용
- 내보내기 오디오: 음 높이 유지(WSOLA 방식 시간 늘이기) 또는 가변 속도(음 높이가 속도를 따라감). 역재생 클립 소리도 미리보기·내보내기에 나옴

### 오디오
- 3밴드 EQ, 하이패스, 로우패스, 밴드패스, 컴프레서, **노이즈 게이트**(AudioWorklet), **험 제거**(50/60 Hz), 리버브, 딜레이, 증폭
- 오디오 믹서(페이더·좌우·음소거/솔로·트랙 미터), 마스터 볼륨·레벨 미터, 노멀라이즈(-1 dB)
- **자동 더킹**: 목소리 트랙의 파형에서 말하는 구간을 찾아 음악 볼륨에 키프레임
- **오디오 추출**: 영상에서 소리만 새 파일로 만들기 — 파일 전체, 소스 시작~끝 표시 구간, 또는 타임라인 클립이 쓰는 부분. WAV / M4A(AAC) / Ogg(Opus), 원본과 같은 형식이면 다시 압축하지 않고 복사. 프로젝트에 추가하거나 파일로 저장하고, 원래 클립 위치에 맞춰 빈 오디오 트랙에 놓을 수도 있음(프로젝트 패널·타임라인 클립 오른쪽 클릭, 클립 메뉴)
- **보이스오버 녹음**: 오디오 트랙 머리글의 마이크 버튼 → 재생헤드부터 녹음해 그 트랙에 바로 넣기(마이크 권한 필요)

### 멀티캠
- 프로젝트 패널에서 영상 여러 개 선택 → **멀티캠 소스 시퀀스 만들기**(소리 파형 / 시작 표시 / 파일 시작으로 동기화)
- **멀티캠 패널**: 모든 앵글을 격자로 보며 클릭 또는 숫자 키 1~9로 전환. 재생 중에 누르면 그 위치에서 잘라 바뀜

### 텍스트 / 자막
- 텍스트 레이어: 크기, 굵게/기울임, 정렬, 행간, 자간, 외곽선, 배경 상자, 타자기 효과
- **글꼴 74종 + 내 글꼴**: 한글 글꼴 37종(고딕·명조·제목용·손글씨, Google Fonts), 영문 디자인 글꼴 30종, 시스템 글꼴 7종. 글꼴 선택 창에서 실제 문구로 미리 보고, 마우스를 올리면 화면에 바로 적용되어 보임(Esc로 취소). 글꼴 파일(.ttf .otf .woff .woff2) 가져오기, Chrome·Edge에서는 이 컴퓨터에 설치된 글꼴 목록 불러오기. Google 글꼴은 쓸 때만 내려받음
- **타이틀 템플릿**: 하단 자막바, 가운데 제목, 엔드 카드, 구독 버튼, 장소 표시, 챕터, 인용구
- SRT 자막 가져오기/내보내기
- **자동 자막(음성 인식)**: 브라우저 안에서 Whisper 모델(transformers.js) 실행, 한국어 등 7개 언어, 자막 길이 나누기 — 아래 제한 참고

### 스코프
파형(밝기), RGB 퍼레이드, 히스토그램, 벡터스코프(피부색 선)

### 내보내기
- **프리셋**: 유튜브 1080p / 4K, 쇼츠·릴스·틱톡, 최고 화질, 작은 파일, 웹용 WebM, 움짤(GIF), 소리만(WAV)
- MP4 / WebM: WebCodecs로 프레임 단위 정확 렌더링(미리보기와 같은 합성 엔진), 크기·화질·범위·프레임 속도 지정
- **GIF**(256색 팔레트, 디더링), 소리만 WAV / M4A / Ogg, PNG(현재 프레임)

## 알려진 제한 (정직하게)
- **자동 자막은 실제 모델로 시험하지 못했습니다.** 개발 환경에서 jsdelivr·huggingface.co 다운로드가 막혀 있었습니다. 처음 쓸 때 라이브러리와 모델(약 40~250MB)을 인터넷에서 받아야 하며, claude.ai 아티팩트 보기 화면처럼 외부 다운로드가 막힌 곳에서는 작동하지 않습니다
- 보이스오버 녹음은 마이크 권한이 필요합니다. claude.ai 아티팩트 보기 화면에서는 마이크가 막혀 있어 쓸 수 없습니다(테스트는 Chromium 가짜 마이크로 함)
- 손떨림 보정은 화면 전체의 이동·회전만 추정하는 단순한 방식입니다. 원근 왜곡이나 롤링 셔터는 보정하지 못합니다
- 자동 리프레임은 가운데 기준으로 자릅니다. 피사체를 따라가지 않습니다
- 미리보기는 `<video>` 요소 동기화 방식이라 복잡한 타임라인에서 프레임이 빠질 수 있습니다. 내보내기는 프레임 단위로 정확합니다. 미리보기의 속도 램프 소리는 근사치입니다
- 아주 긴 4K 프로젝트는 브라우저 메모리와 속도 한계에 걸릴 수 있습니다
- M4A(AAC) 만들기는 브라우저에 AAC 인코더가 있어야 합니다. 개발 환경의 Chromium에는 없어 **시험하지 못했고**, 없으면 메뉴에 "사용 불가"로 표시됩니다. MP3로 저장하는 기능은 없습니다
- Pretendard, 나눔스퀘어 등 Google Fonts에 없는 글꼴은 목록에 없습니다. 글꼴 파일을 받아 "글꼴 파일 가져오기"로 넣으면 쓸 수 있습니다
- 브라우저가 예약한 단축키(Ctrl+N, Ctrl+T, Ctrl+W 등)는 쓸 수 없어 메뉴로 대신합니다
- 프로젝트 파일에는 미디어가 들어가지 않습니다. 다른 컴퓨터에서는 "미디어 다시 연결"이 필요합니다

## 구조

```
index.html            레이아웃
styles/app.css        스타일 (--ui-scale 로 크기 조절)
src/main.js           시작, 패널 배치, 상태 표시줄
src/store.js          상태·선택·스냅숏 기반 실행 취소
src/model.js          프로젝트/시퀀스/클립 모델, 키프레임·시간 다시 매핑 계산
src/easing.js         키프레임 이징 곡선 (Robert Penner 방식 공식)
```
