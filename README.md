# Montage — 브라우저 영상 편집기

Premiere Pro의 작업 방식(프로젝트 패널 → 소스/프로그램 모니터 → 멀티트랙 타임라인 → 이펙트 컨트롤 → 내보내기)을 본뜬 **브라우저 기반 비선형 영상 편집기(NLE)**입니다. 설치나 서버 없이 브라우저 안에서만 동작하고, 미디어 파일은 사용자 컴퓨터 밖으로 나가지 않습니다.

> Adobe와 무관한 독립 구현입니다. Adobe 코드·디자인·상표를 사용하지 않았고, 단축키와 패널 구성 같은 작업 흐름만 참고했습니다.

## 실행 방법

ES 모듈을 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 정적 웹 서버로 열어야 합니다.

```bash
# 저장소 루트에서 아래 중 하나
python3 -m http.server 8000
npx serve .
```

브라우저에서 `http://localhost:8000` 을 엽니다. 빌드 단계는 없습니다.

**권장 브라우저:** 최신 Chrome / Edge. WebCodecs, Canvas `filter`, WebGL을 사용합니다.
- MP4(H.264/AAC) 디코딩·인코딩은 브라우저 코덱 지원에 따라 달라집니다. H.264를 지원하지 않는 브라우저(예: 일부 Linux 빌드의 Chromium)에서는 WebM(VP9/Opus) 파일을 쓰거나 WebM으로 내보내면 됩니다. 이때 MP4 컨테이너에는 사용 가능한 다른 코덱이 자동으로 선택됩니다.
- Firefox와 Safari는 일부 기능(캔버스 필터, WebCodecs 인코더 종류)이 제한될 수 있습니다. 테스트는 Chromium에서만 했습니다.

## 기능

### 프로젝트 / 미디어
- 영상·오디오·이미지 가져오기: 파일 선택, 드래그 앤 드롭, 타임라인에 바로 드롭
- 썸네일, 필름스트립, 오디오 웨이브폼 자동 생성. 아이콘 보기에서 마우스를 올리면 프레임을 훑어볼 수 있음
- 컬러 매트, 블랙 비디오, 조정 레이어, 텍스트, 도형(사각형·타원·삼각형·선, 그라디언트 채우기)
- 미디어 오프라인 표시와 재연결(파일 이름 기준 일괄 재연결)
- **자동 저장**: 프로젝트와 가져온 파일을 브라우저 IndexedDB에 저장하므로 새로고침 후에도 복원됩니다
- 프로젝트 파일(`.montage.json`) 저장/열기

### 시퀀스 / 타임라인
- **여러 시퀀스**(타임라인 탭), 시퀀스 설정(해상도 프리셋·프레임레이트), 시퀀스 복제·삭제
- **중첩(Nest)**: 선택한 클립을 새 시퀀스로 묶음. 중첩 시퀀스 안의 영상과 오디오가 모두 렌더링·재생·내보내기됨. 더블클릭하면 중첩 시퀀스가 열림
- 비디오/오디오 트랙 추가·삭제, 잠금, 출력 토글(눈), 뮤트/솔로, 트랙 볼륨, 타기팅
- 도구: 선택(V), 트랙 앞으로 선택(A), 리플 편집(B), 롤링 편집(N), 레이저(C), 슬립(Y), 손(H), 확대(Z), 문자(T)
- 덮어쓰기/삽입 이동(Ctrl+드래그), 복제(Alt+드래그), 마키 선택, 스냅(S), 연결 선택, 링크/링크 해제
- 리플 삭제, 갭 선택 후 삭제, 들어올리기/추출(; '), Q/W 리플 트림, Ctrl+K 편집점 추가, 1프레임 이동(Alt+←/→)
- 마커(이름·색·메모), 시퀀스 In/Out, 매치 프레임(F), 장면 편집 자동 감지(컷 또는 마커 생성)
- 오디오 볼륨 러버밴드 드래그, Ctrl+클릭으로 볼륨 키프레임 추가
- 실행 취소/다시 실행(최대 200단계)과 히스토리 패널

### 모니터
- 소스 모니터: In/Out 지정, 삽입(,)/덮어쓰기(.), 비디오만/오디오만 드래그, J/K/L 셔틀
- 프로그램 모니터: 재생 해상도(자동/Full/½/¼), 확대 비율, 세이프 마진, 루프, 현재 프레임 PNG 저장
- 화면에서 직접 클립 이동·크기 조절·회전, 문자 도구로 클릭한 위치에 텍스트 생성

### 이펙트 컨트롤 / 키프레임
- 고정 이펙트: 모션(위치·크기·회전·기준점), 불투명도와 블렌드 모드 17종, 볼륨, 패너
- 스톱워치 키프레임, 키프레임 이동(◀ ◆ ▶), 키프레임 레인 드래그, 보간(선형·이즈·홀드)
- 숫자 값은 드래그로 조절(Shift ×10, Ctrl ×0.1)하거나 클릭해서 직접 입력

### 비디오 이펙트
밝기/대비, 기본 색보정(노출·대비·채도·색온도·틴트), 색조 이동, 틴트, 흑백, 세피아, 반전, 가우시안 블러, 샤픈, 엣지 검출, 포스터라이즈, 모자이크, 비네트, 글로우, 필름 그레인, **컬러 키(크로마키, WebGL)**, 드롭 섀도, 자르기, 가로/세로 뒤집기, 레터박스, 카메라 흔들림

### 트랜지션
비디오: 크로스 디졸브, 검정으로 디졸브, 흰색으로 디졸브, 와이프, 푸시, 아이리스 원형 · 오디오: 일정 전력(Constant Power), 일정 게인(Constant Gain)
(편집점 중앙 정렬 양면 트랜지션, 또는 클립 시작/끝의 단면 페이드)

### 오디오
- 오디오 이펙트: 3밴드 파라메트릭 EQ, 하이패스, 로우패스, 밴드패스(전화음), 컴프레서, 리버브, 딜레이, 증폭
- 오디오 트랙 믹서(페이더·팬·뮤트/솔로·트랙 미터), 마스터 볼륨, 마스터 레벨 미터
- 노멀라이즈(피크 -1 dB)

### 텍스트 / 자막
- 텍스트 레이어: 폰트(한글 웹폰트 포함), 크기, 굵게/기울임, 정렬, 행간, 자간, 외곽선, 배경 박스, 타자기 효과(Reveal 키프레임)
- SRT 자막 가져오기(새 트랙에 텍스트 클립으로 생성)와 내보내기

### 속도
- 속도/길이 대화상자(링크·리플), 역재생, 프레임 고정(Add Frame Hold)

### 스코프
- 루마 파형, RGB 퍼레이드, 히스토그램, 벡터스코프

### 내보내기
- **MP4 / WebM**: WebCodecs 기반으로 프레임 단위로 정확하게 렌더링합니다(미리보기와 같은 합성 엔진 사용). 출력 크기, 품질, 범위(전체/In-Out)를 지정할 수 있습니다
- WAV(오디오만), PNG(현재 프레임)

## 알려진 제한
- 모든 처리가 브라우저 안에서 이루어집니다. 아주 긴 4K 프로젝트는 메모리와 속도 한계에 걸릴 수 있습니다
- 미리보기는 `<video>` 요소 동기화 방식이라 복잡한 타임라인에서 프레임이 빠질 수 있습니다. 내보내기는 프레임 단위로 정확합니다
- 역재생 클립은 미리보기에서 소리가 나지 않습니다. 속도를 바꾼 클립의 소리는 미리보기에서는 음높이가 유지되지만, 내보내기에서는 재샘플링되어 음높이가 바뀝니다
- 브라우저가 예약한 단축키(Ctrl+N, Ctrl+T, Ctrl+W 등)는 사용할 수 없어 메뉴로 대신합니다
- 프로젝트 파일에는 미디어가 포함되지 않습니다. 다른 컴퓨터에서 열면 "Link Media…"로 다시 연결해야 합니다

## 구조

```
index.html            레이아웃
styles/app.css        스타일
src/main.js           부트스트랩
src/store.js          상태·선택·스냅숏 기반 실행 취소
src/model.js          프로젝트/시퀀스/클립 모델, 키프레임 계산
src/edit.js           편집 연산(삽입·덮어쓰기·리플·트림·중첩 등)
src/effects.js        이펙트/트랜지션 정의
src/compositor.js     합성 엔진(미리보기·내보내기 공용), WebGL 키어
src/playback.js       재생·미디어 동기화·오디오 그래프
src/audio-fx.js       오디오 이펙트 체인
src/export.js         WebCodecs 내보내기, 오프라인 오디오 믹스
src/media.js          가져오기·분석(썸네일·웨이브폼)·장면 감지
src/persist.js        IndexedDB 자동 저장, 프로젝트 파일
src/commands.js       메뉴/단축키 공용 명령
src/shortcuts.js      키보드 단축키(한글 입력기 상태에서도 동작하도록 KeyboardEvent.code 사용)
src/ui/*.js           패널 UI
vendor/mediabunny     미디어 디코딩/인코딩 라이브러리(MPL-2.0, 수정 없이 포함)
```

## 라이선스 참고
`vendor/mediabunny/`는 [mediabunny](https://github.com/Vanilagy/mediabunny)(MPL-2.0)를 수정하지 않고 그대로 포함한 것입니다. 라이선스 전문은 같은 폴더에 있습니다.
